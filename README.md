# Capstone-Project-RealEstate-Insights-Gurgaon-ML-engineering-
Machine Learning & Core Pipeline Workflow
1. Data Acquisition & AggregationThe dataset was natively built by web scraping residential real estate listings from 99acres. Raw data collection culminated in two primary subsets: houses.csv and flats.csv. Merging these structural subsets yielded a unified database containing ~4,000 observations across 14 to 16 feature columns, establishing a robust baseline for market analysis.
2. Data Cleaning & Structural PreprocessingTo prepare the dataset for analysis, an aggressive data-cleansing pipeline was executed:Deduplication: Identified and eliminated duplicate rows to prevent downstream data redundancy.Structural Renaming: Standardized raw scraped column headers into clean, human-readable semantic variables.Initial Missing Value Management: Isolated and mapped the structural voids within the data.
3. Advanced Feature Engineering & Specialized ImputationDue to the messy nature of real-world real estate listings, resolving missing data and engineering granular attributes was a primary focus:Area Dimension Modeling: Property dimensions were split across three distinct categories: built_up_area, super_builtup_area, and carpet_area. Mathematical ratio constraints based on sector medians were derived to impute missing metrics across these interconnected dimensions.Categorical Imputation: High-volume missing records in agePossession and furnish_details were systematically resolved using a custom three-tier mode imputation strategy grouped by sector and property type.Unstructured Feature Extraction: Semi-structured "Features" and "Amenities" strings were parsed using a MultiLabelBinarizer to calculate an objective, weighted luxury_score for every listed property.
4. Statistical Outlier Detection & TreatmentTo protect model optimization from anomaly-driven bias, columns were evaluated based on their distribution properties:Parametric Features: Handled via standard Z-score thresholds where data distribution approximated normality.Non-Parametric Features: Evaluated via Interquartile Range (IQR) gating coupled with boxplot visualizations to truncate extreme values and unrepresentative price spikes safely.
5. Multi-Criteria Feature Selection & Explainable AI (XAI)To reduce dimensionality, eliminate multi-collinearity, and combat overfitting, features were evaluated across a rigorous 8-parameter feature selection framework:LASSO ($L_1$ Regularization) CoefsPearson/Spearman Correlation AnalysisRandom Forest Feature ImportanceGradient Boosting Feature ImportancePermutation Importance ScoresOrdinary Least Squares (OLS) Linear WeightsRecursive Feature Elimination (RFE)SHAP (SHapley Additive exPlanations): Utilized to interpret the global feature impact and local marginal contributions toward final property valuations.
6. Robust Scikit-Learn Preprocessing PipelinesTo prevent target-variable skewness from breaking regression assumptions, a log1p transformation was applied to the pricing column. To guarantee zero data leakage during validation, all processing logic was encapsulated cleanly within a Scikit-Learn ColumnTransformer:High-Cardinality Categoricals: Handled via TargetEncoder (specifically for the complex sector layout of Gurgaon).Nominal Categoricals: Processed via OneHotEncoder.Ordinal Categoricals: Mapped via OrdinalEncoder.Numerical Metrics: Normalized via StandardScaler.
7. Benchmarking, Hyperparameter Tuning & SerializationMultiple regressor architectures (including Random Forest, SVR, and XGBoost) were benchmarked using a rigorous 10-Fold GridSearchCV routine. The top-performing configuration evaluated by its R^2 score was selected as the core inference engine. The final model pipeline was serialized into pipeline.pkl and the clean reference dataframe into df.pkl.
8. Geospatial Analysis & Coordinate MappingA dedicated geospatial processing script (latlong.py) was constructed to append coordinate boundaries (Latitude/Longitude) to Gurgaon sectors, allowing the application to execute accurate spatial decisions and distance calculations.
9. Multi-Weighted Recommendation EngineUsing real estate data from apartments.csv, a customized recommendation engine was constructed by establishing three independent similarity matrices using Cosine Similarity:Matrix
i: Location Advantage (Geospatial proximity to landmarks and transport hubs)Matrix
ii: Price Profile Similarity (Target budget and price-per-sqft alignment)Matrix
iii: Top Facilities Index (Premium amenities and luxury score alignment)By applying explicit structural weights to these matrices, the engine outputs the Top 5 most comparable properties whenever a user selects a specific location or residential complex.
